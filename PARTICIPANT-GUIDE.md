# Audience guide

## Learning objectives

- Understand how ORLEN locations can be modelled as multi-energy retail destinations.
- See how real-time data, ML, and agents support one operational decision.
- Distinguish analytical insight from governed operational action.
- Evaluate value for customers and ORLEN using measurable outcomes.

## Observation prompts

### 1. Observe the trigger

Identify which live signals materially change the customer journey or ORLEN economics.

### 2. Challenge the prediction

Ask whether the model improves on a fixed rule, whether confidence is visible, and which business metric it is intended to improve.

### 3. Challenge the agent

Inspect its evidence, tool choices, permissions, denied actions, and human approval boundary.

### 4. Validate the outcome

Confirm that the final scorecard contains both customer and ORLEN measures and distinguishes synthetic assumptions from measured results.

## Discussion questions

1. Which operational decision would create the fastest measurable value at ORLEN?
2. Which action can be automated safely, and which must remain human-approved?
3. Which source systems and market differences must be represented in a first pilot?
